= Linkinator
:description: Click-time outbound link validity hints with muted colors, sharp borders, and an archive.org / Wayback button.
:page-orig-author: Ryan Johnson
:page-last-edited: 2026-10-16

**Linkinator** is a separate Antora UI bolt-on from build-time https://github.com/antora-supplemental/link-validator[link-validator] / https://github.com/antora-supplemental/asciidoc-link-validator[asciidoc-link-validator].

== What it does

* Wraps outbound `http(s)` anchors in `article.doc` prose only (skips header, footer, and `page-context` metadata)
* Muted validity background + **sharp** 1px border (ok / invalid / unchecked / …)
* archive.org **Wayback** control as an **Archive** pill beside the link (`.lini-actions`), shown on block/link hover — not embedded in prose
* Optional live probe via `window.LINKINATOR_PROBE_URL` proxy (no secrets in the page)

== Install

[source,bash]
----
pnpm add -D github:antora-supplemental/linkinator#v0.1.0
# or track main:
pnpm add -D github:antora-supplemental/linkinator#main
----

== Playbook

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/linkinator'
      statusDefault: unchecked
----

When `injectAssets` is true (default), the extension publishes `/_/css/linkinator.css` + `/_/js/linkinator.js` and injects `<link>` / `<script>` tags into composed pages (after `site.js`). Hubs may mirror assets in supplemental UI but should not duplicate script tags.

== Live probe (`LINKINATOR_PROBE_URL`)

Browsers cannot reliably CORS-`HEAD` arbitrary outbound URLs. For live status on hover, point the page at a **same-origin or CORS-enabled proxy**:

[source,html]
----
<script>
  // IMPORTANT: include the trailing "?url=" — the client appends encodeURIComponent(href)
  window.LINKINATOR_PROBE_URL = 'https://YOUR_PROXY/probe?url='
</script>
----

Behavior:

* If `window.LINKINATOR_PROBE_URL` is **unset**, Linkinator sets status to `unknown` for `data-lini-live="true"` anchors.
* If set, the client calls `fetch(LINKINATOR_PROBE_URL + encodeURIComponent(href))` and expects JSON `{ ok, status }` (`status`: `ok` | `invalid` | `unknown` | …).

Reference probe (alongside the CI dispatch proxy):

https://github.com/antora-supplemental/asciidoc-link-validator/tree/main/examples/dispatch-proxy[`asciidoc-link-validator/examples/dispatch-proxy`] — `GET /probe?url=`

Env on that stub: `PROBE_ALLOWLIST` (optional host suffix allowlist), `CORS_ORIGIN`.
