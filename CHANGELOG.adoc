= Changelog

== 0.1.12 — 2026-10-21

* **Body-only scope:** auto-detect `[data-zone="body"]` and wrap external links only inside that subtree (no page-context / header / meta exclude list when zoned).
* **Legacy flat articles:** minimal default `exclude` (`.page-context`, `.page-context-source-line`) when no body zone is present.

== 0.1.11 — 2026-10-21

* **Metadata exclusions:** configurable `exclude` selectors (default skips `.page-context`, `.page-context-source-line`, `.page-context-source-actions`, `[data-zone="header"]`, `[data-zone="meta"]`) so View|Edit and page-context links are never wrapped.
* **Optional scope:** `scope` or auto-detect `[data-zone="body"]` limits wrapping to article body zones when the theme segments the article.

== 0.1.10 — 2026-10-17

* **Wayback chip hover/focus:** `.lini-wayback` keeps an opaque `--valentus-elevated` base on `:hover`, `:active`, and `:focus-visible` (accent tint via `color-mix`, not transparent `--valentus-accent-soft`).

== 0.1.9 — 2026-10-17

* **Inline external icon:** every wrapped link shows a small in-flow `.lini-ext` affordance beside the anchor.
* **Hover Archive:** Wayback archive control floats next to the external icon on link-cluster hover (`display: none` when idle); `::after` bridge for click path.

== 0.1.8 — 2026-10-17

* **Wayback chip placement:** `.lini-actions` anchors to the link’s right edge (`left: 100%` + gap), vertically centered (`top: 50%` / `translateY(-50%)`) instead of floating above the line.
* **Hover bridge:** `.lini::after` hit area spans the gap to the chip so moving from link → ⧉ does not dismiss the control before click.

== 0.1.7 — 2026-10-17

* **Zero layout footprint:** idle `.lini-actions` uses `display: none` (not opacity-only in flow); `span.lini` is `inline-block` sized by the anchor only so the ⧉ chip never reserves line space until hover.
* **Transparent at rest:** `a.lini-link` matches theme prose links (no default border/background/pill); hover/focus adds `--valentus-accent-soft`. Validity borders appear only after live probe (`.is-status-visible`).

== 0.1.6 — 2026-10-17

* Restore pre-v0.1.4 **⧉** Wayback icon (icon-only control, no inline “Archive” label).
* **Floating overlay:** `.lini-actions` is `position: absolute` above the link (out of prose line flow); hover tint stays on `a.lini-link` only.

== 0.1.5 — 2026-10-17

* **Link-row hover only:** drop `.lini-block` on parent `p`/`li`/…; hover tint and Archive reveal apply to compact `span.lini` (anchor + pill), not whole bullets or paragraphs.

== 0.1.4 — 2026-10-17

* **Styled hover chrome:** block wrapper (`.lini-block`) tints on hover/focus-within using Valentus `--valentus-*` tokens; Wayback control is a compact **Archive** pill beside the link (`.lini-actions`), hidden until hover.
* **Assets on published pages:** injects `linkinator.css` + `linkinator.js` `<link>` / `<script>` tags (after `site.js`) so hubs do not need duplicate supplemental-ui copies.

== 0.1.3 — 2026-10-16

* Display name **Linkinator** (replaces informal “Link-inator”) in registry metadata, docs, and extension-lister labels.

== 0.1.2 — 2026-10-16

* Wrap outbound links only inside `article.doc` prose — skip site header, footer, and `aside.page-context` metadata.
* Wayback control moves to a compact hover/focus bar (`.lini-hoverbar`) instead of an inline button beside every link.

== 0.1.0 — 2026-09-27

* Initial scaffold: `wrapExternalLinks`, Wayback button, muted status CSS (sharp borders), Antora `sitePublished` register, registry metadata export, tests.
